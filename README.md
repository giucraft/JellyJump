# JellyJump 🐰

A cheerful, fluffy-themed endless jumper. Tap or press Space to jump, dodge obstacles, collect jelly drops and discover new friends.

## Play locally
Open `index.html` in a browser. For install/offline testing, serve the folder over HTTPS or localhost.

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.
4. Wait for GitHub Pages to publish the site.

On iPhone, open the published HTTPS address in Safari, tap Share, then **Add to Home Screen**.

All characters and artwork in this starter are original simple game illustrations/emoji placeholders; the game can be expanded with custom fluffy character art.
